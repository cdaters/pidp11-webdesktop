# Reporting security issues

This is experimental software. There is no supported production Pi deployment or stable security-maintenance promise yet. Use the loopback demonstration and isolated lab as documented; do not expose guest Telnet, raw terminal sockets or panel RPC services to the Internet.

Please report exploitable issues through this repository's **Security → Report a vulnerability** feature rather than a public issue. If that option is unavailable, contact Craig Daters through [RetroRealm.org](https://retrorealm.org/) to arrange a private report. Include the affected commit, a small reproduction and expected impact. Do not send private disk images, access tokens or unrelated personal data.

Ordinary bugs and questions belong in Issues or Discussions. The [known limitations](docs/known-limitations.md) distinguish current terminal, authentication and panel-control boundaries. No browser disconnect is evidence that a PDP-11 CPU stopped.
