> The reference desk and exact calculator run without a model. When I configure a local model, the gateway receives only the question, bounded context and text I deliberately choose to share. Answers are experimental. The separately enabled command-proposal trial is restricted to three reviewed UNIX suggestions with explicit human approval; ordinary chat has no authority to operate Linux, SIMH or the panel.

> The target remains one small compiled service with the browser assets inside it. It needs no graphical desktop, runtime Node, database or container on the Pi. Its candidate installation is stopped and disabled by default, starts without a guest attachment, and refuses startup without effective memory and zero-swap limits. A fresh approval follows independent guest-line verification. Before an intentional guest change, I stop the actual bridge; merely closing a browser does not establish that boundary.
