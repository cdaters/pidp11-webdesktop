# M5.19 — Genuine terminal workstation

M5.19 advances the browser workstation for both physical PiDP-11 owners and ordinary
SIMH users. It adds useful terminal controls and a durable equipment roadmap while
preserving the independently operated emulator and original console. Development
and tests ran on the Mac and disposable, network-none ARM64 Linux copies. No
physical Pi, SSH or GPIO access occurred. Original installations and media were
preserved; no upstream repository, website or release was modified. Release metadata
was inspected read-only for preservation checks.

The [product direction](../product/virtual-computer-room.md) makes genuine equipment
interaction the destination. The next recommended equipment milestone is a real
printer/paper-tape guest workflow, building on the existing device observations.
The [resume handoff](../../RESUME.md) is linked from repository instructions so a
fresh session can recover scope, checkpoints, limits and missing private evidence.

## What changed

- Genuine terminal windows gain explicit equipment/connection descriptions,
  observer/keyboard authority, selected generation and disconnect behavior.
  The descriptor grants no permission and requires no physical panel.
- Local search, Previous/Next match, selection/copy, retained-text selection,
  latest-output navigation and screen focus complement existing bounded export,
  reviewed paste and independent terminal windows.
- On-screen Esc, LF, PF, numeric keypad and VT220 editing keys help laptop users.
  VT52 keypad modifiers and unsupported modern editing keys are handled explicitly;
  VT220 adds F13–F20/Help/Do and DECID. VT100 DA/DECID now identify the base VT100
  subset rather than advertising later xterm capabilities. All replies and keys
  still require the current lease.
- Six validated display preferences cover phosphor, brightness, text size, cursor,
  scanlines and glow. They cannot restore a connection, guest identity, keyboard
  lease or emulator state. Default effects are off; reduced-motion/high-contrast
  preferences suppress effects. Geometry remains fixed rather than sending an
  unrequested terminal resize to the guest.
- Optional browser audio uses received BEL events, never a demonstration timer.
  It starts muted, needs an explicit gesture, has per-window/global mute and volume,
  suppresses hidden/unfocused output and shares one bounded audio context. An OSC
  terminator is not a BEL event. Teletype output also participates. The tone is a
  synthetic approximation, not a recording or mechanical emulation.

The [workstation guide](../technical/terminal-workstation.md) gives operating steps;
the [capability inventory](../technical/terminal-personalities.md) distinguishes
implemented subsets, xterm extensions, guest driver responsibilities and omissions.
No new dependency, Go control endpoint, automatic reconnection or emulator-control
path was added. The ordinary panel and media controls remain simulations.

## Findings and corrected test attempts

1. BSD `robots` produced a partial initial board. Retained incoming bytes also
   lacked the complete tail; the browser did not merely hide a complete transcript.
   A documented Ctrl-L redraw restored the board. This recurred in all final
   engines; the precise guest/curses/serial/transport cause remains unisolated.
   Do not count this as an unqualified full-screen compatibility pass.
2. An exploratory teleport could legitimately kill the player. The first test
   incorrectly expected a live-game quit prompt afterward. The retained screen
   showed the game-end prompt and return to shell. The final bounded test uses a
   normal step, whose movement or blocked-step response is verified.
3. The first BEL probe used an older `awk` without an explicit `exit`. It remained
   waiting for input, and an earlier game bell could satisfy an insufficient count
   assertion. The original console identified the running application; it was
   interrupted once through the approved browser. Final tests require a new BEL
   count and shell prompt from `awk 'BEGIN {printf "%c",7;exit}'`. Earlier counts
   are not used as successful BEL evidence.
4. EDT pauses after a keypad TYPE command. An early test sent Ctrl-Z into that
   pause instead of waiting for **Press return to continue**. The corrected test
   acknowledges that actual prompt, then verifies return to line mode. The initial
   edited file was preserved and saved; new filenames were used for final cases.
5. Exploratory BSD logins reached the unchanged 16-session bound and got HTTP 503.
   No limit was raised. After verifying the guest was idle, the exact optional
   bridge was stopped and restarted detached, then its known line explicitly
   approved again. The first restart helper refused its existing private control
   directory before starting a process; that helper was corrected, with the failed
   attempt retained. The emulator and original console continued independently.
6. RSX's timed startup date prompt expired before the reply. MCR rejected the late
   date as an illegal command; it was not resent. The guest retained its distribution
   date, 30-Dec-2018. Offline network-device messages were retained; the container
   had no external interface. No guest clock value is used as the test's wall time.
7. Browser test development corrected selectors that accidentally matched the mock
   terminal as well as the guest, and the window's full accessible Close name.
   These fixture errors were retained. Final focus behavior also brings the screen
   back into view and collapses its settings on **Focus terminal**.

The original ARM64 exit-139 incidents and V7 plotting timeout remain unresolved;
this terminal milestone neither reproduced nor diagnosed them. It does not extend
LP11/PC11 CPU/device observations into qualified guest printer-driver integrations.
Independent security review, authoritative guest identity, upstream Hacker Replicant
approval and physical deployment/control qualification remain outstanding.

## Automated, resource and accessibility checks

The final verification summary is in [verification.json](../../lab/m519/results/verification.json).
Go vet and the uncached race suite passed (22 tested packages); TypeScript checking,
105 frontend units, one transport integration fixture and nine independent-client
selection-contract cases passed. All **129 final three-engine cases passed**. The suite includes terminal bytes,
lease gating, paste/reconnection, generation changes, effects, search, preference
validation and optional audio. Separate audio fixtures test per-window/global mute,
focus, hidden-document suppression and context cleanup; real browser AudioContext
checks verify successful gesture activation. They do not measure speaker audibility.
A clean local clone installs and builds independently. Build output retains the
existing warning about a bundle over 500 kB; no new package was added.

| Final workstation build | Private static ARM64 executable 8,061,090 bytes; self-contained demo 571,936 bytes; not published binaries |

Retain the [Pi 3B+ engineering budgets](../roadmap.md#performance-targets): ≤24 MiB idle
companion RSS, ≤48 MiB active / ≤64 MiB observed peak, <1% idle / <5% mean active CPU
of one core (<10% p95), with the later 96 MiB enforced ceiling and zero swap. Add
a terminal-specific target of ≤100 ms p95 local round-trip. Browser targets are
bounded scrollback, ≤5 ms p95 consumption in this local fixture, fast default effects
off and no retained transcript growth. These are budgets for later representative
qualification, not proof that this Mac/VM result meets every Pi target. A physical Pi
without the required memory controller still cannot claim enforced MemoryMax.

Keyboard-operable labeled controls, live connection/status messages, fixed cursor,
reduced-motion/effect suppression, contrast settings and explicit focus behavior
were exercised. Existing screen-reader mode remains enabled. No native Safari,
physical assistive technology, historical keyboard hardware or speaker/listening
session was tested; Playwright WebKit is not native Safari certification.

## Preservation and handoff

Actual bridges were stopped before guest shutdown. V7's original operator and
conventional serial sessions still answered; BSD, RSX and RT-11 original consoles
also remained usable. V7 synced three times before SIMH quit. BSD reached
`syncing disks... done`, halting and HALT; RSX reached final dismount, SHUTUP
completion and HALT; RT-11 returned to its idle monitor. All four owned containers
exited zero and were removed. Working disks and private evidence were retained.
Original source hashes and recorded metadata were rechecked. Details are in
[preservation.json](../../lab/m519/results/preservation.json).

Source Alpha 1, Source Alpha 2, accepted tag refs and their published assets remain
unchanged. M5.19 is development-main work only. No new release, binary upload,
announcement, production deployment or hardware approval is implied. Public results
are curated aggregates; `.research/m519/` remains local/private and is not recovered
by cloning GitHub. Use [RESUME.md](../../RESUME.md) for the next session's checkpoint
and the [equipment roadmap](../product/virtual-computer-room.md) for the next scope.
