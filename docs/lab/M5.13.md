## Outcome and publication boundary

Recommend an experimental **source-only** alpha for local demonstrations and
controlled genuine-guest labs. The candidate and checksum record are supplied
separately for owner review. Ordinary engineering commits are authorized; a public
release tag, GitHub Release, stable release or downloadable binary still requires
explicit owner approval. Physical/general Pi deployment remains NO-GO.

The external review packets are preparation by the implementation author, **not
independent security or historical acceptance**. Unknown OS changes inside a
surviving SIMH process and socket remain undetectable. The operator supplies the
guest identity assertion; neither a pidfd nor an executable hash proves that OS.
