# M4.3 terminal compatibility and session matrix

2026-11-17. xterm.js **6.0.0** and FitAddon **0.11.0**, lazily loaded in the existing TypeScript desktop. These are renderer/transport fixtures, not evidence of a guest OS login, editor, terminal driver or a real VT100/VT220 device. Source/manual references and exact byte vectors are in [terminal research](../research/terminal-m43-fixtures.md).

| Area | Implemented/tested scope | Limit |
|---|---|---|
| VT100 / ANSI | DEC G0/G1 special graphics, CUP/default coordinates, relative cursor movement, scroll margins, origin mode, wrap/no-wrap, CR/LF, BS/DEL output, save/restore, reverse index | A tested subset, not full conformance or exact hardware timing |
| VT52 | Negative fixture confirms xterm does not implement DECANM/ESC Y addressing | Profile remains disabled; no cosmetic claim of support |
| VT220 | Insert/delete characters and selective protected erase pass | Partial renderer only; DECSCL, multinational/downloadable sets and user-defined keys unvalidated/unavailable |
| Parser chunking | Every two-part split of 16 independent deterministic screen vectors | Browser glyph rendering separately exercised; not exhaustive fuzzing of xterm |
| Keyboard | Numeric/application keypad encoder, normal/application arrows, PC F1–F4 → DEC PF1–PF4, keypad Enter | Explicit adapter uses xterm mode flags; PC F1 is not a claim about a physical VT220 F1 key; actual keypad hardware/NumLock variants not tested |
| Encoding | Strict ASCII7, explicit Latin-1 byte-to-control mapping, streaming fatal UTF-8 decoder | Latin-1 controls are not DEC multinational character compatibility; mock UI uses Unicode strings |
| Telnet | Offline byte-oriented NVT parser, CR NUL/CR LF, doubled IAC, split negotiations, duplicate suppression, EOF/oversize rejection | Conservatively refuses BINARY, NAWS, TTYPE and other options; not connected to a browser guest endpoint |
| Flow control/backpressure | Offline 64 KiB keyboard queue, XON/XOFF opt-in, 4 KiB drain, overflow disconnect, owner release/reconnect discard | Contract fixture, not production terminal gateway; binary streams must not apply XON/XOFF implicitly |
| Mock input/output | Complete escape-sequence filtering, BS/DEL edit, Ctrl-C, 256-character command line, 4 KiB per input event, 64 KiB pending renderer output | Mock commands only; excessive input rejected; no host shell or panel commands |
| Instance lifecycle | Four independent renderers/sessions, 300-line scrollback, 50-command model history, FitAddon resize and disposal | Window closure releases keyboard and destroys parser; no output-only text replay pretending to reconstruct parser state |
| Ownership | Explicit keyboard acquire/release separate from panel controls; release increments input epoch and discards unfinished line | Local mock ownership only, not remote authorization or a guest-terminal lease |
| DZ11 transport | Original SIMH RAM scanner with two TCP/Telnet lines and independent PTY monitor in isolated Linux | No guest OS, real serial wiring, Screen attachment, production console takeover or browser-to-DZ gateway |

`src/terminal-protocol.ts` deliberately separates byte decoding, key encoding, the mock line editor, bounded session queue and Telnet framing. The pure transport pieces are offline contracts; they are not presented as an already connected terminal service. The browser adapter fixes the M4.2 defect where ESC `[A` or ESC `OP` became printable command tails. Browser tests type arrows/PF keys inside HELP and verify the command remains HELP, then release/reacquire during a partial command and verify no old input is replayed.

Future real session integration must select one authoritative parser/reply owner for device-status reports; multiple observing browsers must not each answer a guest query. It must authenticate terminal observation and keyboard input separately, negotiate dimensions/encoding deliberately, enforce byte and CPU limits, and define whether reconnect restores an authoritative parser snapshot or starts a new parser. A visible-text replay cannot restore margins, modes, character sets or cursor state. No such gateway has been enabled in M4.3.
