# ADR 0009: source facts and independent read-only companion

Status: implemented experimental boundary in M5.9.3 Phase D; live identity acceptance outstanding.

## Context

Phase C’s references helped Gemma but did not eliminate false explanations. Its atomic checker recognized none of the 45 natural responses. Hacker Replicant’s Screen-control architecture, large prompt, status Boolean and cancellation behavior also differed from this desktop’s dedicated guest-line design.

## Decision

Keep exact calculations and explicit source facts ahead of inference. `/calc` and `/fact` validate constrained requests and return without provider/history/terminal sharing. A small fragment checker may annotate an exact recognized clause against a supplied installed note; it must leave surrounding text unverified. Matching a citation or one clause never certifies a complete answer.

Run the optional Hacker Replicant app separately, with a different browser hostname and independent HTTPS authentication. Apply an explicitly documented patch only to the pinned disposable upstream checkout. Use bounded tutor context and intercept the read-only request before upstream’s tool loop. Do not embed a console iframe or convey Web Desktop cookies/tokens. The standard Go ARM64 package gains no Node runtime dependency.

The selected-text adapter has distinct read and publication credentials, endpoint/attachment/simulator identities, bounded expiry, revoke and unknown status. Its standalone manifest is an owner attestation, not an observation of actual guest state. Read-only compatibility is accepted only for the demonstrated synthetic selection; automatic lifecycle tracking and live sharing are not claimed.

## Consequences and limits

The deterministic path is useful offline but covers a small explicit catalog. Natural recognition remains low; independent expert review and broader whole-response annotation are needed. Citation withholding catches nonexistent references, not incorrect reasoning. An app can cancel a request but cannot recall already delivered data or prove immediate model idleness.

The optional app has a single-owner selection slot and HTTP Basic credentials; it needs dedicated security/session review before wider deployment. Separate credentials protect services from the model and each other only within their documented roles: the Node process intentionally holds publication authority and must be trusted by its owner. Compromising that process could misuse its excerpt permissions, though no endpoint grants emulator control.

No choice here changes the terminal bridge’s authentication, leases, generations, detached startup, mandatory memory containment, disabled autostart, command allowlist or physical-control restrictions. [Measured evidence](../lab/M5.9.3-D.md) and [setup/unsent proposal](../../integrations/hacker-replicant/README.md) define the present scope.
