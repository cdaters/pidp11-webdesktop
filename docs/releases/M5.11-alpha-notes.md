# M5.11 preview notes

`m5.11-preview.1` is a source-built Linux ARM64 laboratory candidate, not a stable release or accepted Pi deployment. It advances the M5.10/Phase D runtime with narrowly scoped integration fixes.

- Bind selected-text consent to an exact receipt and prevent late publication after revocation. Reject malformed chat elements in the separately modified optional Hacker Replicant app.
- Expose private viewer-lifetime observations for a separate lab guard; add no emulator, host-shell, GPIO or public keyboard authority.
- Make peripheral shutdown permanent and detect rewritten bytes in the retained spool window.
- Add five historical notes and two deterministic facts, with fresh source/model evaluation and explicit missed contradictions.
- Record genuine V7/BSD lifecycle checks, RSX-11M-PLUS browser commands, RT-11/RSTS console inventories, real-guest sharing and original LP11/PC11 output.
- Exercise the companion beside an independent genuine guest under protected ARM64 systemd, including upgrade, rollback, memory refusal and removal.

The final executable and its package checks are identified in the [M5.11 report](https://github.com/cdaters/pidp11-webdesktop/blob/main/docs/lab/M5.11.md) and [qualification record](https://github.com/cdaters/pidp11-webdesktop/blob/main/lab/m511/results/package.json). No guest disks, manuals, model weights, private evidence or laboratory containers are distributed in the package. The sharing guard and modified Node application remain separate experiments; they are not deployment requirements or automatically installed services.

The original PiDP-11 must work independently. Effective memory containment, HTTPS/private role tokens and explicit guest-line approval remain mandatory. Missing containment means refusal, not a watchdog substitute. Stop the actual bridge before intentional guest changes. A surviving stream does not establish OS identity. Physical repair, actual Pi memory readiness, independent review and longer representative measurements remain open.
