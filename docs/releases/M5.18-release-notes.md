# PiDP-11 Web Desktop — Source Alpha 2

**Public experimental source-only pre-release.** Tag:
`v0.5.17-source-alpha.2`, pointing to `38bcfad84dc0b100005542f3aee6752ee147c649`.

**Source Alpha 2 is intended for local demonstrations and controlled historical-computing laboratories. It is not an approved installation for physical PiDP-11 hardware.** The Web Desktop is optional: original physical controls, LEDs,
SSH, GNU Screen, operator console and supported serial/network guest access must
remain independent of it.

## What improved since Alpha 1

- Handled provisioning failures remove only files created by that invocation;
  private dependencies are synced before config is written last. Existing or
  unknown data is preserved. This is not power-loss or SIGKILL atomicity.
- Private configuration/socket errors give clearer guidance without echoing
  secret input. Node prerequisites and `npm run doctor` help diagnose setup.
- The optional standalone selected-text client freezes the exact approved
  snapshot before asynchronous requests. The optional Hacker Replicant module
  checks cancellation before delivering delayed model replies.
- Real authenticated Go/Node TLS tests cover capability negotiation, separate
  credentials, exact receipts, replacement, expiry, revocation and concurrent
  publication. The compact security packet maps 21 invariants to 47 named tests.
- Bounded native process diagnostics and unique plotting evidence improve future
  fault investigation. Additional tutor tests retain source-status safeguards;
  citations do not certify generated prose.

See [the detailed change inventory](https://github.com/cdaters/pidp11-webdesktop/blob/38bcfad84dc0b100005542f3aee6752ee147c649/docs/releases/M5.17-changes.md).
Alpha 1 remains unchanged and does not contain these later corrections.

## Start the no-Pi demonstration

Install Node.js **22.18 or newer** with npm. Obtain the approved archive and checksum
file together in a new folder. In a **Mac shell**:

```sh
shasum -a 256 -c SHA256SUMS
tar -tzf pidp11-webdesktop-m5.17-source-alpha.2.tar.gz
tar -xzf pidp11-webdesktop-m5.17-source-alpha.2.tar.gz
cd pidp11-webdesktop-m5.17-source-alpha.2
shasum -a 256 -c SOURCE_SHA256SUMS
npm ci
npm run doctor
npm run dev
```

Stop at a failed checksum or command. Inspect the listing before extracting; use
only the reviewed ordinary source members under the one named root. Open the
actual loopback URL printed by Vite. Restore the DEC terminal, acquire its keyboard
and type `HELP`; this is a labeled local fixture. Try a sample printer job, offline
reference search and `/calc 16 oct 177776`. The ordinary browser front panel and disk, tape and other media controls remain
simulated. No guest, model, Go or Docker is required.
Stop with Ctrl-C and verify the URL no longer loads.

The [candidate quick start](https://github.com/cdaters/pidp11-webdesktop/blob/38bcfad84dc0b100005542f3aee6752ee147c649/docs/getting-started/source-alpha-2.md)
explains prerequisites, simulated equipment, shutdown and removal.
[Genuine guest labs](https://github.com/cdaters/pidp11-webdesktop/blob/38bcfad84dc0b100005542f3aee6752ee147c649/lab/m516/README.md)
are a separate advanced path using authorized disposable media, never the Pi.
The pinned quick start retains its candidate-era publication wording; this release
records the approved published identity.

## Qualified scope and remaining concerns

The exact extracted source passed Go vet/full uncached race, 102 frontend units,
114 Chromium/Firefox/WebKit cases, three-engine onboarding, the named security
suite, actual TLS and restricted Linux process/ownership checks. Its private ARM64
rebuild matches the previously qualified runtime. A separate Debian ARM64 kernel
refused unbounded startup, accepted 96 MiB/zero swap and stopped cleanly.

Fresh original-SIMH regressions passed V7 terminals/plotting, BSD vi/pager/readback,
RSX HELLO/HELP/PIP, RT-11FB application echo/retype/AST, and original LP11/PC11 CPU
programs with exact completed downloads. These are lab results, not physical Pi
acceptance, full terminal conformance or guest printer-driver qualification.

Independent security review is pending. The two original ARM64 exit-139 incidents
and initial V7 plotting timeout remain unresolved. Guest OS identity is operator-
attested; a surviving process/socket can conceal an OS change. Revocation cannot
recall text already delivered to a page or model. The optional 0.1 `/screen` route
retains a missing-receipt compatibility exception; the qualified client supplies
and verifies exact receipts. A future receipt-required `/selected-text` route is
only a proposal. Hacker Replicant has not approved or implemented this contract
upstream; Rolf's interest is not endorsement.

RT-11 provides application I/O, not an independent browser login shell or complete
MTTEST acceptance. RSTS/E remains console-only. Optional AI explanations remain experimental and fallible;
source references and notices are not factual certification. Physical switch
repair, effective Pi memory control, representative resource measurements,
observer privilege review and renewed supervised coexistence remain deployment
gates. Physical Pi deployment and remote physical-panel control are not authorized.
No automatic emulator lifecycle or remote physical-panel authority is added.
