# Source Alpha 2: changes since Alpha 1

Alpha 1 remains the immutable M5.13 source at
`ef643e59e5040adcbf7f7b1286fe3472ff08a00f`. The candidate consolidates the changes
below; it does not expand production authority. See the [candidate quick start](../getting-started/source-alpha-2.md).

| Area | Already in Alpha 1 | Added after Alpha 1 |
|---|---|---|
| Provisioning | Private configuration, explicit fresh-directory provision, owner checks | M5.14 syncs created files and writes config last; handled failure removes only owned outputs and preserves unknown files. Not crash-atomic cleanup. |
| Setup | Node/npm local demonstration | Prerequisite checks before install/start and `npm run doctor`; clearer private JSON/socket failure guidance without echoing secret input. |
| Consent | Explicit sharing, epochs, exact receipt checks in the optional app | Standalone 0.1 adapter; M5.15 copies the approved selection before asynchronous status lookup and checks cancellation after delayed model replies. |
| Capability contract | Experimental authenticated adapter | Version/authority/bounds checks, actual Go/Node TLS probe, multi-caller replacement/global revocation qualification; compatibility `/screen` still permits absent receipt headers. |
| Fault evidence | Two unexplained ARM64 provisioning exits | Bounded native wait-status capture, mount/resource evidence, exclusive plotting campaigns and direct/tapped byte progression. Original faults remain unresolved. |
| Tutor | Offline references, exact arithmetic, source notices and quotation safeguards | Additional negative tests ensure citations cannot grant certification or suppress source-status notices; no new semantic truth detector or held-out tuning. |
| Review | M5.13 review packet | M5.16 compact 21-invariant/47-test packet, restricted Linux tests and M5.17 independent-finding intake. External review pending. |
| Onboarding | Source-only no-Pi demo | Troubleshooting, candidate-specific extraction/integrity checks and three-engine onboarding qualification. |

Production changes are confined to provisioning/diagnostics, setup checks and
optional integration modules. M5.16 and M5.17 add qualification tools/tests/docs;
no new front-panel authority, automatic guest identity or emulator lifecycle is
introduced. The browser package's `0.5.0` development identifier is separate from
the proposed source release tag `v0.5.17-source-alpha.2`, consistent with Alpha 1's
milestone-based naming. No Alpha 2 tag or release is created by preparation.

## Audience boundaries

The local no-Pi demonstration uses simulated equipment and mock terminals. Genuine
V7/BSD/RSX/RT-11 and LP11/PC11 results belong to authorized disposable laboratories.
RT-11 is application I/O, not an independent browser shell or complete MTTEST pass.
RSTS/E remains console-only. CPU/device tests do not qualify guest printer drivers.

Hacker Replicant integration is optional, experimental and not approved upstream.
The proposed receipt-required `/selected-text` route is design only. Physical Pi
installation remains unsuitable pending hardware repair, effective memory cgroups,
representative performance, observer privilege review and renewed supervised
coexistence. Historical panel-control restrictions remain unchanged.
