# PiDP-11 Web Desktop — Source Alpha 3

**Draft for owner review. Not published.** Proposed tag: `v0.5.29-source-alpha.3`.
The exact candidate commit and archive identity are recorded in the
[M5.29 qualification report](../lab/M5.29.md); they must be rechecked before any
separately authorized publication.

**Source Alpha 3 is intended for local demonstrations and controlled
historical-computing laboratories. It is not an approved installation for physical
PiDP-11 hardware.** This is experimental source software, not a binary installer.

Since Source Alpha 2, development has added practical terminal controls, supervised
printer/paper-tape workflows, retained job history, captured storage observations
and bounded serial/local-modem text workflows. Documentation and real screenshots
now distinguish current interfaces from historical guest evidence and simulations.

UNIX V7, 2.11BSD and RSX browser subsets have genuine laboratory evidence. RT-11 has
application-level terminal I/O and separately tested printer/tape utilities, not
an independent browser login shell. RSTS/E remains console-only. Genuine RSX/RT-11
printer and paper-tape subsets extend the older CPU/device tests; other guest
printer-driver integrations are not qualified. Storage views are captures, not
continuous live activity or browser media controls.

The separate TM11 activity experiment remains laboratory-only and missed its
incremental-memory target. Genuine BSD Ethernet required a separate original-source
SIMH build and a strictly isolated TAP. Its retained packet summaries are not a
live browser networking feature, and the experimental executable is not bundled.

The ordinary front panel and demonstration equipment remain simulated. Guest OS
identity is not automatically authoritative. Optional AI explanations remain
experimental. Earlier Hacker Replicant evidence used an explicitly modified pinned
copy; the proposed 0.2 contract is not implemented or approved upstream support.
Independent security review has not occurred. The original ARM64 exit-139 incidents
and V7 plotting timeout remain unresolved.

The browser remains optional. Original physical controls, LEDs, SIMH/REALCONS,
SSH, Screen, operator console and supported independent guest access must remain
usable without it. Physical Pi deployment and remote physical-panel control are
not authorized. No guest media, model weights, native binaries, credentials or
private transcripts belong in the release.

The proposed attachments are only the verified source archive and `SHA256SUMS`.
Alpha 1, Alpha 2 and all accepted tags/assets remain unchanged.
