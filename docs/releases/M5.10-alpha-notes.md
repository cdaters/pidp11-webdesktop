# M5.10 preview notes

`m5.10-preview.1` presents the existing Phase D application with refreshed documentation, onboarding and authentic screenshots. It is a Linux ARM64 laboratory candidate, not a stable release or accepted physical deployment.

## Changes

- Reorganized the README and documentation around what a newcomer can run, with a current capability matrix and consolidated limits.
- Captured fresh V7 commands, VT52/teletype presentation, Tektronix plotting, 2.11BSD `vi`, and original LP11/PC11 device observations in disposable Mac-hosted labs.
- Preserved Phase D real-model, offline-reference, arithmetic and modified Hacker Replicant evidence with explicit provenance.
- Updated beginner troubleshooting, alpha-package guidance and installation examples. Prepared a separate website editorial handoff; no website deployment.
- Corrected versioned packaging to include these notes instead of the older M5.9.2 report. No application behavior change is intended.

## Requirements and limits

Use [installation paths](../getting-started/installation-paths.md) and the [optional-service procedure](../getting-started/optional-service.md). The target requires Linux ARM64, systemd, enforceable cgroup v2 memory/zero-swap limits, HTTPS and explicit guest-line approval. No runtime Node, database or container is required.

The original PiDP-11, physical panel and console remain independent. SR0 repair, memory-controller readiness and renewed physical acceptance are outstanding. Genuine device tests do not qualify OS printer drivers. Models still make errors; narrow claim review does not certify an answer. Hacker Replicant interoperability uses a modified experimental app, not a supported integration.
